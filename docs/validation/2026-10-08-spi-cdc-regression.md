# SPI→USB 加入后的回归与并发瓶颈

本轮对比 SPI 功能加入前后的固件与 Web，并验证 F103ZE 实机上的 RTT、JScope/HSS、调试、烧录及 ADC。SPI 未启用时与 SPI 持续接收时分别测量，不能把空闲结果当成并发性能保证。

## 条件与对照

- 探针 HPM5301EVKLite akaLinkPro，序号 `B4444F2110DDDAFE44800BBB0AE800E0`，CDC COM5，USB 高速；Windows、Chrome 153、同一接线与主机。
- 目标 SWD 实读 F103ZE：Flash 512 KiB、RAM 64 KiB。RTT 速率夹具为 96 MHz；HSS 与 SPI 发送夹具为 72 MHz。
- 功能加入前：探针 `ef4808b`、Web `88d3eaa`。加入后起点：探针 `6c82edd`、Web `0bf30f7`。最终产物包含本轮修复，哈希见同目录原始记录。
- 先备份目标全部 Flash，结束恢复并校验；探针保留最终修复固件。

## 未启用 SPI：原有功能没有测出明显速率下降

相同夹具、时钟和测量窗口，硬件测试串行执行，避免相互占用探针。RTT 转发的脚本虽显示 MB/s，计算实际是 **MiB/s**；SPI 接收报告使用十进制 MB/s。

| 项目 | 功能加入前 | 加入后初次对照 | 结论 |
| --- | --- | --- | --- |
| RTT 转发，60 MHz | 2.89 / 2.90 MiB/s | 2.92 / 2.92 MiB/s | 没有下降 |
| RTT Viewer | 582.6 / 575.5 KiB/s | 557.1 / 510.5 KiB/s；补测 575.4 | 有主机轮询波动，补测接近基线 |
| JScope，1 变量、2 µs | 495.62 / 495.61 kHz | 495.87 / 495.87 kHz | 接近基线 |
| JScope，3 变量、2 µs | 110.10 / 110.29 kHz | 110.08 / 110.06 kHz | 接近基线 |
| JScope，1/3 变量、20 µs | 50 kHz，约 20–27 ppm 探针跳拍 | 同量级 | USB 丢样本、包缺口均为 0 |
| HSS，1 变量、3 µs，72 MHz 目标 | 333.326 kHz | 333.327 kHz | 接近基线；样本高位、计数方向、包顺序检查通过 |
| 原生 RTT 序号流，45 MHz | 2531–2533 KiB/s | 2540–2543 KiB/s | 无缺序号、重复、回退或读写错误 |

原生 RTT 基线首个窗口有 1 个坏帧，另两个窗口为 0；加入后三个窗口均为 0。STOP 边界的探针搬运与主机接收计数可差 2048 B，不能据此推断稳定窗口内丢包。原始日志保留这些差异。

60 MHz 的连接/切换并非每次稳定：最终首轮完整流程第二次 RTT START 自动退到 45 MHz，严格档位断言失败；第一次 Viewer 连接也出现 NO ACK 后重试成功。固件既有 RTT 扫描失败及链路恢复逻辑会降档，本轮没有修改该逻辑。保留失败日志，并单独列出后续完整流程结果；这些结果不能证明当前接线下 60 MHz 始终可靠。

## 开启 SPI：找到并修复两处实际影响

SPI 18 MHz 持续输入约 2.25 MB/s，同时运行 HSS；每组预热后测量约 5 秒。

| 采样配置 | 修复前实测 / 探针跳拍 | 修复后实测 / 探针跳拍 |
| --- | --- | --- |
| 1 变量、2 µs | 35.156 kHz / 92.968% | 428.648 kHz / 14.270% |
| 1 变量、3 µs | 8.514 kHz / 97.446% | 294.909 kHz / 11.527% |
| 1 变量、20 µs | 0.550 kHz / 98.901% | 50.000 kHz / 0% |
| 8 变量、100 µs | 0.550 kHz / 94.507% | 10.000 kHz / 0% |

探针原 `forward()` 在每次复制后重新读取 DMA 写入位置，会追着新到字节继续搬，直到耗完 4096 B 预算。18 MHz 下这一轮可能拖到约 1.8 ms，挤占下一次采样。修复为只搬函数入口时已有的数据，新到数据留给下一轮主循环；仍保留复制块上限、预算、覆盖丢弃及 CDC 在途存储保护。生产服务宿主测试模拟复制期间又收到 50 B，断言第一次只搬入口的 100 B，第二次再搬 50 B。

Web 的另一处影响是：采样已有多个原生 USB 读请求，在低实际速率下 40 ms 内排不完。STOP 后重启原本要求整设备复位，被正在工作的 HID/CDC 占用保护阻止。修复按实测吞吐量有界等待生产者排空；必要时关闭采样独占的 WebUSB 句柄以取消原生请求，然后重开。实测 Windows 仅 `releaseInterface` 不足以取消所有请求，最终采用句柄关闭。其他 WebUSB 使用者存在时仍保留共享占用保护；没有绕过整设备复位保护。四组连续停止、重启与收尾均完成。

修复后的四个稳定测量窗口：SPI 2.247–2.251 MB/s，新增缺帧、坏字节、乱序、探针 dropped、FIFO/DMA 错误均为 0；HSS 的 USB 丢样本、读错误、包乱序、无效高位、计数回退均为 0。

**并发上限仍然存在。** 最大速率请求还有 11–14% 探针跳拍，是探针共享执行时间造成的降速。SPI 在采样标定/初始化期间还有覆盖丢弃：最终四组预热结束时累计 dropped 为 34,486 / 48,432 / 62,189 / 179,713 B，并伴随帧缺口与重新同步；不能把稳定窗口的零错误说成从启动到停止全程无损。2/3 µs 用例停止排空阶段的 HSS 总计 USB 丢样本分别为 714 / 195，稳定窗口为 0，其他两组总计为 0。连续 SPI 与采样切换时应根据完整计数评估，需要全程无损的场景需进一步优化初始化/标定调度或控制输入。

## 最终检查与原始证据

最终完整流程、ADC 矩阵、离线/宿主检查和页面回归的结果及产物哈希在 `2026-10-08-spi-cdc-regression/`。该目录保留对照、并发修复前后、最终回归及初次失败记录。

- 最终 `make full_flow_f103ze` 重跑：主流程 20/0、调试压力 82/0；两轮 RTT 转发均约 2.90 MiB/s，1 变量约 495.7 kHz，3 变量分别 109.57 / 94.20 kHz。低速率档跳拍 13–27 ppm，USB/缺口为 0。极限速率只断言跑通，其中一次停止后报告 USB 丢样本 78，不能视作高采样率零丢弃保证。调试中 8 次 FAULT 重试恢复，没有意外目标复位；本轮未提供 GDB oracle，未做 GDB 行为对照。
- 最终 HSS 稳定窗口补测：1 变量 2/2.25/3 µs 分别 495.760 / 444.031 / 333.328 kHz；八变量 20 µs 为 50.000 kHz，跳拍 0。七组样本高位错误、计数回退、包乱序、稳定窗口 USB 丢样本/读错误均为 0；高负载组启动/停止总计 USB 丢样本非零，保留完整计数。
- ADC 实机：317/0，共 61 次采集；8/10/12/16 位，1 kSa/s–2 MSa/s、8192 点跨 DMA 圈尾、12 组持续采集，无溢出。验证计数、位宽、速率切换、DMA 圈尾、序号、传输与收尾；没有外部标定信号，不能证明电压精度。
- CMSIS-DAP/OpenOCD：1/2/4/10/20/36/45/60 MHz 各读写 20 KiB，逐字节匹配。脚本预期归一到 64 MHz，但实际读得目标 72 MHz，以实读时钟为准。
- 最终 `make test-host` 与 `make test-offline` 通过；离线首次失败来自旧模拟器的永不结束读取，已模拟真实句柄关闭后取消原生读取，继续验证共享使用者保护后全量重跑通过。局部变量的旧地址断言改用独立固定快照。
- 八类真实 DOM 回归通过：SPI 主机 168/0、屏 179/0、I²C 145/0、采样、调试 156/0、ADC 游标/测量、SPI→USB、串口高流量记录。首次 SPI 主机页失败是导航断言仍预期旧标签顺序；更新后全量重跑。SPI 主机/屏、I²C 等使用假探针验证，不冒充外接器件实测。未覆盖未连接的 H743、HPM6800 等目标。

目标恢复后读回全部 524,288 B，与测试前备份逐字节相同，SHA256 为 `c2ed64c452949005c057cb0d0e58c1dde508e7296962022d4f88aabd56faba98`。最终探针 ELF SHA256 为 `1c69dbed8e34a94e235d1a01bd3111bf8fdb55a8a318208cc8550326f20af0cf`，发送端 ELF 为 `9d8beec01e09dcca0b4a1e063c4bb489ecd536da8318713075eb79f8a1efbc0a`。

探针固件与测试目标的重新编译 ELF 随源码提交；局部变量单元测试使用固定 CFI 快照，与供用户下载的可重建 ELF 分开，避免不同编译器改变地址导致假回归。
