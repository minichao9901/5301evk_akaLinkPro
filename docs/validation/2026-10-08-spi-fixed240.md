# SPI2 模块固定 240 MHz：实现与实测

日期：2026-10-08。探针：HPM5301EVKLite / akaLinkPro，SN B4444F2110DDDAFE44800BBB0AE800E0。

## 实现

- SPI/QSPI 主机、SPI→CDC 从机共同调用 `spi_bridge_configure_clock()`，固定 SPI2 内部模块为 240 MHz。先查询 PLL0 CLK0，再一次设置 /3，避免扫描时短暂输入 720 MHz。
- 每次启动都核验实际频率；失败有界退出。SPI转发返回 -4 并释放资源，主机关闭使能并请求复位。
- 保留 32 B 配置协议及偏移 24 的 `module_clk_hz` 字段，兼容旧网页。旧客户端写 0、120 MHz 等提示值都归一化为 240 MHz，GET_CFG 回读 240000000。
- 主机 SCK 仍按请求分频，实际不超过请求。SDK 要求偶数分频 N≤510、整数 Hz 且整除；10/20/40/60 MHz 精确生成，75/100 MHz 请求降到 60 MHz。保留原 100 MHz 请求上限，不新增 120 MHz 输出档。最低支持 480 kHz，更低请求拒绝。
- Web 默认配置、假探针和分频断言同步；网页仍以 STATUS 回读实际 SCK。SPI转发外部 SCK 来自发送板，不受主机分频档位限制。

## SPI/QSPI 发图通路

Chrome 153、真实 WebUSB，整屏 BMP → RGB565 → 线上 XFER → 最后应答及 DRAIN 完成围栏。AXS15352 为 240×296、单线 SPI；ST77916 为 360×360、QSPI 四线。每档 20 轮，8 KiB/32 KiB 批次，20/40/60/75 MHz 请求。**本轮没有接屏**，只验证传输执行和计数，不能据此证明屏显示或引脚电气完整性。

以下为像素有效载荷除以传输时间，单位十进制 MB/s，批次 32 KiB。历史基线为同日 `word-dma-full.json`；并非严格交替 A/B，百分比仅为观察，短测试与系统调度也会影响结果。

| 面板/线路 | 实际 SCK | 历史动态模块时钟 | 固定 240 MHz | 观察变化 |
| --- | ---: | ---: | ---: | ---: |
| AXS15352 / SPI | 40 MHz | 4.428 | 4.425 | 约持平 |
| AXS15352 / SPI | 60 MHz | 6.180 | 6.290 | +1.8% |
| ST77916 / QSPI | 40 MHz | 13.137 | 13.164 | 约持平 |
| ST77916 / QSPI | 60 MHz | 16.358 | 16.766 | +2.5% |

所有 16 个发图组合 `framesErr/outOverrun/inDrop` 增量为 0，帧数和发送字节全部对账。USB-only 32 KiB 约 18.44 MB/s。包含图片处理、UI 与调度的完整墙钟速率低于表中传输速率，例如 60 MHz/32 KiB 的 SPI 约 4.77、QSPI 约 10.13 MB/s，详见原始数据。

75 MHz 请求现实际为 60 MHz，不能将其与旧固件实际 75 MHz 直接比较。提高模块时钟不会直接提高线上 SCK；主机侧收益较小，且固定时钟减少了可用 SCK 档位。

## H743 → SPI转发 → CDC

H743 PA4/5/7 → 探针 PB10/11/13，共地，Mode 0 / MSB。发送夹具使用 64 B SPIC 帧、连续序号、56 B 已知变化载荷。H743 的 MHz 为 HSI/PLL 标称值，非示波器读数。此次探针冷启动后的第一个 SPI 服务就是从机接收，脚本 **`--module-mhz 0`**，没有先启用主机调时钟。

| 外部 SCK 标称值 | 稳定窗口 | 主机实收 MB/s | 校验帧数 | 载荷位错误 / 缺帧 / 失步 |
| --- | ---: | ---: | ---: | --- |
| 60 MHz | 15 秒 | 7.532 | 1,765,434 | 0 / 0 / 0 |
| 66 MHz | 15 秒 | 8.286 | 1,942,123 | 0 / 0 / 0 |
| 67 MHz | 15 秒 | 8.412 | 1,971,638 | 0 / 0 / 0 |

三档稳定窗口探针丢弃/FIFO 溢出/DMA 故障均为 0，H743 补缓冲迟到及 DMA 错误均为 0。载荷 BER 为有限测试中的 0；不是对无限时长无误码的保证。SWD 启停阶段仍有累计丢弃，完整 before/after/stopped 保留；该阶段不纳入稳定窗口。

真实 Web 66 MHz / 15 秒还进行了接收缓冲对照：

| WebSerial 接收缓冲 | 实收 MB/s | 稳定窗口缺帧 | 失步字节计数 bad | 探针丢弃增量 |
| --- | ---: | ---: | ---: | ---: |
| 生产默认 4 KiB | 8.272 | 3,086 | 440 | 195,528 B |
| 测试临时 64 KiB | 8.284 | 0 | 0 | 0 B |

两轮均无 FIFO/DMA 错误，Web 心跳最大间隔约 35 ms，没有卡死。`bad` 是测试解析器的失步扫描计数，不能称为 SPI 位误码。该对照支持接收背压为这轮丢字节的原因；native 同速率无误码。**生产网页缓冲仍为 4 KiB**，64 KiB 仅用于测试，并在 finally 恢复；扩大默认值仍需 RTT 等共享串口回归，本次不将它混入时钟改动。
